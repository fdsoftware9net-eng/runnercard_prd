## ขั้นตอนแรกที่แนะนำ

**อย่าเพิ่งเขียนโค้ดส่งข้อมูล** ให้ทำ 2 อย่างนี้ก่อน

**1. ทำลายเซ็นให้ตรงก่อน**
รันตัวอย่างใน `api-reference.md` หัวข้อ 2.3 และ 2.4 แล้วเทียบว่าได้ค่าเดียวกับที่เอกสารเขียนไว้
`samples/sign.py` รันแล้วจะพิมพ์ `MATCH` ถ้าถูกต้อง
ถ้ายังไม่ตรง อย่าเพิ่งเขียนต่อ — ปัญหาส่วนใหญ่จบที่ขั้นนี้

**2. ยิงจริง 1 ครั้ง แล้วดูว่าได้ `403 authority_moved`**

```json
{ "error": "authority_moved" }
```

✅ **นี่คือคำตอบที่ถูกต้องในตอนนี้** ไม่ใช่ความผิดพลาด

แปลว่า key ของท่านใช้ได้ ลายเซ็นถูกต้อง สิทธิ์ถูกต้อง — แต่เรายัง **ไม่เปิดช่วงเวลาให้เขียนข้อมูล**
ผู้จัดจะเป็นคนกำหนดวันเปิด แล้วเราจะแจ้งท่าน

ถ้าได้ `403 forbidden` (ไม่ใช่ `authority_moved`) แปลว่าตั้งค่า key ผิด — แจ้งเรา

## หลังจากเราเปิดให้แล้ว

ใช้ `"dry_run": true` ก่อนเสมอในการส่งชุดข้อมูลรูปแบบใหม่ครั้งแรก
จะได้รายงานหน้าตาเหมือนกันทุกอย่าง แต่ไม่เขียนข้อมูลจริง
